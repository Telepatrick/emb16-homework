# emb16-homework
## Модуль 2.4. Домашнє завдання: Усунення брязкоту контактів кнопки
### Хід роботи
Всі 5 сценарії реалізовано у одній прошивці через завдання значеннь 1-5 для DEBOUNCE_MODE відповідно до номеру завдання.

#### Завдання 1: Базова реалізація (без debounce)
Реалізовано алгоритм що викликає переривання на каожному спадаючому фронті.
В свою чергу коне переривання викликає наступні дії:
 - інкрементування лічильнику переривань;
 - вивод значення лічильника у лог.

#### Завдання 2: Software debounce через таймер (time-based)
Реалізовано антибрязкіт на основі часу, ігноруючи переривання, якщо з моменту попереднього пройшло < 50 мс, поза ISR.

#### Завдання 3: Debounce через перевірку рівня (state-based)
Реалізовано алгоритм в якому переривання  лише сигналізує “подія”.
Далі у основному циклу відбувається наступне:
 - приймамо подію лише якщо кнопка досі натиснута;
 - ігноруємо події при відпусканні.

#### Завдання 4: Polling + debounce (без interrupts)
Через паттерн state machine реалізовано опитування кнопки без переривань.

#### Завдання 5: Hardware debounce
Додано RC-фільтр (конденсатор 100n і резистор 100R, підтягуючий незмінний 10k)
Проведено виміри, результати додано до таблиці.

### Висновок
Вході виконання завдання опановано 5 різних методів усунення брязкіту, як програмних, так і аппаратних, результати додано у порівняльну талбицю. Можна зробити висновок що найменш часо-затратне танадійне - програмне усунення брязкоту.
