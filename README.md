# emb16-homework
## Модуль 3.1. Домашнє завдання: Калібрування даних з ADC
### Хід роботи:
1. Підключено 10 кОм потенціометр з виходом на АЦП пін 4;
2. У [main.cpp](src/main.cpp) додано код який реалізує наступний алгортим:
    - Ініціюємо АЦП з максимально доступнмми параметрами - розряднстю 12, та атенюацією 12 дБ,та калібрування Curve Fitting у функції init_hw();
    - Зчитуємо чисте значення з АЦП;
    - Вираховуємо каліброване значення завдяки функції adc_cali_raw_to_voltage();
    - Робимо підрахунок напруги використовуючи чисте значення, опорну напругу та кількість кроків АЦП;
    - Виводимо дані форматовані під строку таблиці сумісну з .md файлом;
    - Чекаємо 100 мс перед наступним циклом.
