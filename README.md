# emb16-homework
## Модуль 1.6. Домашнє завдання: Вимірювання освітленості за допомогою LDR та ESP32-S3
### Хід роботи:
1. Підключено фоторезистор та 10 кОм резистор послідовно;
2. Точку контакта двох резисторів підключено до АЦП піну 4;
3. У [main.cpp](src/main.cpp) додано код який реалізує наступний алгортим:
    - Встяновлюємо зчитувавння значень з максимально допустимою нашому АЦП розрядністю 12, та атенюацію у 11 дБ;
    - Зчитуємо чисте значення з АЦП;
    - Зчитуємо підготовлене значення у мілівольтах;
    - Робимо підрахунок напруги використовуючи чисте значення, опорну напругу та кількість кроків АЦП;
    - Виводимо дані форматовані під строку таблиці сумісну з .md файлом;
    - Чекаємо 100 мс перед наступним циклом.

### Результат:
Проведено дослідження по зняттю показань з фоторезистора із записом у таблицю.
