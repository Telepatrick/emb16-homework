# emb16-homework
## Модуль 3.1. Домашнє завдання: Проста ковзна середня (SMA)
### Хід роботи:
1. Зібрано схему з ldr фоторезистором підключиеним до цифрового піна 4 через 10 кОм резистор як подільник напруги, та світлодіодом підключеним до цифрового піна 5 через резистор 220 Ом.
2. У файлі [main.c](src/main.c) створено прошивку що реалізує наступний алгоритм:
 - розроблено структуру sma_filter_t та відповідні функції sma_init() і sma_update() для реалізації згладжування даних через кільцевий буфер розміром N = 10;
 - додано функцію яка налаштовую піни для світлодіода, ADC1 у режимі Oneshot;
 - головна функція app_main() визиває ініціювання периферії та SMA-фільтер викликаючи описані вище функції, далі у циклі використовуючи гистерезис, керує станом світлодіоду.

### Результат:
Під час виконання роботи опановано алгоритм SMA-фільтрації сигналу, підібрано пороги гистерезису для активації-деактивації освітлення. Приклад роботи надано у .gif анімації:
