# emb16-homework
## Модуль 3.3. Домашнє завдання: Широтно Імпульсна Модуляція (PWM)
### Хід роботи:
1. Зібрано схему з потенціометром, підключеним до аналогового піна (GPIO1/ADC1_CH0), світлодіодом, підключеним до цифрового піна GPIO4 через резистор 220 Ом, та DC-двигуном, підключеним до цифрового піна GPIO5 через транзистор 2N2222 та захисним зворотним діодом.
2. У файлі [main.c](src/main.c) створено прошивку, що реалізує наступний алгоритм:
 - розроблено функцію `init_hw()` для налаштування периферії: АЦП (ADC1) у режимі Oneshot для зчитування потенціометра та таймера/каналів LEDC (PWM) для світлодіода і двигуна;
 - налаштовано два незалежні канали ШІМ (`LEDC_CHANNEL_0` для світлодіода та `LEDC_CHANNEL_1` для DC-двигуна), що забезпечує їх автономну роботу;
 - головна функція `app_main()` викликає `init_hw()`, після чого у безкінечному циклі зчитує значення з потенціометра та пропорційно змінює яскравість світлодіода й швидкість обертання вала двигуна.

### Результат:
Під час виконання роботи опановано принцип роботи ШІМ (LEDC) в ESP-IDF, підключення потужного навантаження через транзистор із захисним діодом та забезпечення незалежного керування кількома виконавчими пристроями від одного джерела аналогового сигналу.
