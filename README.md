# emb16-homework
## Модуль 2.1. Домашнє завдання: Embedded C++ на ESP32

### Хід роботи
У файлі [main.cpp](src/main.cpp) реалізовано наступний алгоритм:
 - піни, інтервали та ітерації винесені у окреимй клас Config;
 - ініціалізація світлодіоду та керування ним винесено у окремий клас Led;
 - режими роботи світлодіоду описані у LedMode;
 - клас Application складається з:
    * публічної функції init() що описує ініціалізацію пінів, переривання (*опційне завдання*);
    * публічної функції update() яка фіксує поточний час, перевіряє поточний режим мигання діоду та визиває updateBlink;
    * приватної функції updateBlink яка керує переключенням режиму миготіння;
    * приватної функції processButton() що відстежує натискання кнопки;
    * приватної функції measureLoopTime() - запис кожної 1000 ітерації у лог, та середній час виконання (*опційне завдання*);
    * приватної функції buttonInterrupt() - вміщує значення флагу натискання кнопки buttonPressed_ (*опційне завдання*).
 - ініціалізація application.init() у сервісному методі setup();
 - виклик application.update() всередині основного циклу loop().
    
### Висновок
У ході виконання завдання було використано best practices для контролю embedded застосунку, такі як розгалуження коду на класи конфігурації та бізнес-логіки, замість delay() використано механізми апаратних переривань.
