# emb16-homework

## Мініпроєкт Модуль 3 - Керування сервоприводом

### Хід роботи:
1. Зібрано схему з інкрементальним енкодером, сервоприводом та бузером.
2. У файлі [main.c](src/main.c) створено прошивку, що реалізує наступний алгоритм:
 - розроблено функцію `init_hw()` для єдиного налаштування всієї периферії: апаратного квадратурного декодера PCNT для зчитування сигналів енкодера, таймерів та каналів ШІМ для керування сервоприводом і бузером, а також таймера `esp_timer` для автовимкнення звуку;
 - створено окрему задачу FreeRTOS `encoder_btn_worker()` із обробкою програмного антибрязкоту: коротке натискання кнопки перемикає режим точності (зменшує/відновлює крок повороту вала удвічі), а довге утримання (понад 800 мс) повертає сервопривод у центральне положення (90°);
 - головна функція `app_main()` викликає `init_hw()`, запускає задачу кнопки та у безкінечному циклі опитує лічильник PCNT, обчислює зміну кута, пропорційно переміщує вал сервоприводу та видає короткий звуковий сигнал у разі спроби виходу за крайні положення (0° та 180°).

### Результат:
Під час виконання роботи опановано принцип роботи апаратного квадратурного декодера (PCNT), керування сервоприводом через ШІМ, обробку коротких і довгих натискань кнопок у FreeRTOS та організацію звукової індикації граничних положень.
Приклад роботи надано у [відео](assets/esp32-encoder-servo-control-buzzer.mp4).
